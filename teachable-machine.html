Project Overview

For Project 3, we used Google Teachable Machine to train a five-class image classification model using an original dataset collected by both group members. Our model classifies everyday wardrobe items and personal objects across five categories: Hats, Shirts, Sweatshirts, Shoes, and Random Objects.

Dataset Summary

  • 5 Classes: Hats, Shirts, Sweatshirts, Shoes, and Random Objects
  • 200 Total Images: 100 original images contributed by Romy and 100 by Eddie (20 images per class per member)
  • Data Diversity: Combined across both contributors with varies angles, lighting conditions, backgrounds, and item styles
